# 国内部署指南（腾讯云 CloudBase 云托管）

> 为什么需要这份指南：你的网站主部署在 **EdgeOne Pages**（`*.edgeone.cool`，国内可直连）；这份指南是**备选方案**，教你把同一套代码改走腾讯云 CloudBase「云托管」（`tcb cloudrun`），作为另一种国内部署方式（容灾 / 备选域名）。
> 全程大白话，照着点/敲就行。

---

## 一、你先做的三件事（都需要你的腾讯云账号，别人替不了）

### 1. 注册腾讯云账号
- 打开 https://cloud.tencent.com ，用微信/QQ/邮箱注册一个账号。

### 2. 实名认证（国内云都强制，约几分钟到半天）
- 登录后，右上角头像 → **实名认证** → 选「个人」，按提示填**你本人的身份证**信息。
- 提交后通常很快通过（个别情况半天）。**没实名不能用云开发。**

### 3. 开通云开发 CloudBase 并创建环境
- 打开 https://console.cloud.tencent.com/tcb （这是**国内**控制台，能正常打开；若打不开，也可登录 https://console.cloud.tencent.com 后顶部搜「云开发」进入）
- ⚠️ 别用 `console.cloudbase.net`，那是国际版，国内常打不开
- 点**新建环境**，环境名称随便（如 `child-game`），选**按量计费（有免费额度）**或**基础版**。
- 创建好后，控制台首页能看到一串**环境 ID（envId）**，长这样：`child-game-1a2b3c4d`。**记下来**，待会儿要用。

---

## 二、在你电脑的终端里部署（命令我来教你，你敲）

> 前提：你已经按上面建好了 CloudBase 环境，并且手里有环境 ID。

### 1. 安装 CloudBase 命令行工具
```
npm install -g @cloudbase/cli
```
（这步在你自己电脑上跑，需要 Node.js 18+，你已经有了。）

### 2. 登录（会弹出浏览器让你授权）
```
tcb login
```
点一下授权就行，不用记密码。

### 3. 进入项目文件夹
```
cd "C:\Users\王梓睿\WorkBuddy\孩子的游戏\portfolio-project"
```

### 4. 一键部署到云托管
```
tcb cloudrun deploy --port 3000
```
它会问你三件事，照着选：
- **选择环境 ID**：选你刚建的 `child-game-xxxx`
- **服务名**：填 `child-game`（或随便）
- **是否启用公网访问**：选 **是**（不然只有内网能进）

然后云端会自动构建（几分钟），完成后给你一个域名，形如：
`https://child-game-xxxx.ap-shanghai.app.tcloudbase.com`

**这个域名在国内直接能打开！** 复制给面试官即可。

## 三、让 AI 说真话（可选，部署后做）

网站刚部署时是「试用模式」（AI 用预设回复）。想接真实 AI 对话：

1. 打开 CloudBase 控制台 → **云托管 → 你的服务 → 服务设置 → 环境变量**
2. 添加 `DEEPSEEK_API_KEY`，值填你的 DeepSeek 密钥
3. 保存后会自动重新部署，AI 就「活」了

> 注意：`DEEPSEEK_API_KEY` 是服务端密钥，在控制台填就好，**不要**写进代码或公开仓库。

## 四、常见问题

- **部署时报权限/环境错误**：确认已 `tcb login` 且选对了环境 ID。
- **打开是空白/报错**：先确认在本地 `npm run dev` 本来能跑；若云端打不开，检查是否启用了「公网访问」、环境变量（DEEPSEEK_API_KEY 等）是否填对。
- **想换成自己的域名**（如 `game.wzr0910.cn`）：在控制台「云托管 → 自定义域名」里绑定，需要你有一个已备案的域名。

---

## 五、和 EdgeOne Pages 的关系

- EdgeOne Pages 那份（主部署，`*.edgeone.cool`）建议保留，它是你放简历用的正式域名。
- 本指南的 CloudBase 云托管作为**备选/容灾**：以后改了代码想更新它，重新在项目目录跑 `tcb cloudrun deploy --port 3000` 即可。
