> 这份说明专门写给不熟悉编程的人看。每一步都拆得很碎，照着做就能把网站搬到网上。

一句话：**网站的"功能"已经做好了，现在正把它"搬上网"，让面试官点一个链接就能打开。**

下面这张表是整个过程的全景，✅ 是已经搞定的，⏳ 是还没做的：

| 步骤 | 内容 | 谁来做 | 状态 |
|---|---|---|---|
| 1 | 做网站功能（和 AI 对话、生成"孩子宣言"卡片） | 之前已完成 | ✅ 完成 |
| 2 | 把代码用"备份工具"存一份快照（这步叫 git） | 我帮你做了 | ✅ 完成 |
| 3 | 把代码上传到 GitHub（网上的代码存放处） | **你来做** | ⏳ 待做 |
| 4 | 让 EdgeOne Pages 把网站发布到网上 | **你来做** | ⏳ 待做 |

**已经帮你做好的（第 2 步）说明：**
我在你电脑的 `portfolio-project` 文件夹里，把全部代码用 git 存了一份"快照"（专业叫"提交"），起了个名字叫 `main`。**你的密码和密钥没有被存进去**，放心。

> **为什么要有第 2、3 步？**
> 因为 EdgeOne Pages（帮你把网站放到网上的国内服务）默认从 GitHub 拿代码。所以得先把代码传到 GitHub，EdgeOne 才能拿到并发布。
> 打个比方：GitHub 像是"网盘"，EdgeOne Pages 像是"把网盘里的东西做成网页给大家看"的机器。我们得先把东西存进网盘，机器才能处理。

## 三、按顺序照着做

### 第零步（做"事情 A"之前）：在网页上建一个"空仓库"

1. 打开 github.com，登录你的账号。
2. 点右上角的 **＋**（加号），选 **New repository**（意思是"新建一个代码存放处"）。
3. 仓库名字随便起，比如 `child-game`（孩子游戏）。
4. **重要**：不要用鼠标勾选 "Add a README" 那个选项，让它是个空仓库。
5. 点 **Create repository**（创建）。
6. 创建好后，网页上会显示一串地址，长这样：
   `https://github.com/wzr0910/child-game.git`
   **复制这串地址**，等会儿要用。

### 事情 A：把代码上传到 GitHub（在你电脑的"终端"里敲命令）

> **终端是什么？** 就是电脑里一个可以输入命令的小黑窗。你装了 Git 的话，可以在开始菜单搜 **Git Bash** 打开它，或者用系统自带的 **PowerShell**。

按顺序敲下面三行命令（**第二行的地址，换成你刚复制的那个**）：

```
cd "C:\Users\王梓睿\WorkBuddy\孩子的游戏\portfolio-project"
git remote add origin https://github.com/wzr0910/child-game.git
git push -u origin main
```

每一行敲完按回车：
- **第一行**：进入项目文件夹。因为路径里有中文和空格，所以要加引号，不然电脑会看错。
- **第二行**：告诉电脑"GitHub 上那个空仓库就是我要传过去的地方"，并给它起个代号叫 `origin`。
- **第三行**：把代码上传（专业叫"推送"）上去。

**如果弹出来要登录：**
- 用户名填 `wzr0910`
- 密码那一栏：现在 GitHub 不接受账号密码了，要填 **Personal Access Token**（一种专用密码，在 GitHub 网页的 Settings 里能生成）。如果你电脑上装了 GitHub Desktop 软件并登录过，可能直接就传上去了，不用输密码。

**怎么算成功？** 最后看到一堆文件名滚过、结尾出现 `main -> main` 字样，就说明传成功了。

### 事情 B：在 EdgeOne Pages 上把网站发布出去

1. 打开 EdgeOne Pages 控制台（在腾讯云里搜"EdgeOne Pages"），点 **新建项目 → 导入 Git 仓库**。
2. 授权登录你的 GitHub，在列表里找到你刚传上去的仓库（就是 child-game），点 **Import**（导入）。
3. EdgeOne 会自动认出这是个 Next.js 网站，不用改任何设置，直接点 **部署**。
4. 等一两分钟，网页会给你一个网址，长这样：`https://child-game-xxxx.edgeone.cool`
   这就是你网站的上网地址！点开就能看了。

> ⚠️ **放简历请务必用这个正式域名**，不要放带 `?eo_token=...` 的"预览链接"——预览链接有时效，过一阵就打不开了，招聘方打开会以为是坏链接。

## 四、（可选）让网站功能更完整：填几个"配置项"

网站刚发布时，AI 对话用的是"预设回答"（因为还没接真实密钥）。想让 AI 说真的话、公共画廊能显示所有人的宣言，就在 EdgeOne Pages 里填几个配置：

1. 在 EdgeOne 项目页面点 **环境变量**（Settings / 环境变量）。
2. 逐个添加下面这几个（名字照抄，值填你自己的）：

   | 要填的名字 | 填什么 | 是否必须 |
   |---|---|---|
   | `DEEPSEEK_API_KEY` | DeepSeek 的密钥（想接真实 AI 才需要） | 可选 |
   | `DEEPSEEK_BASE_URL` | 固定填 `https://api.deepseek.com` | 一般不用改 |
   | `CLOUDBASE_ENV_ID` | 腾讯云 CloudBase 环境 ID（接公共画廊才需要） | 可选 |
   | `CLOUDBASE_PUBLISHABLE_KEY` | CloudBase Publishable Key（接公共画廊才需要） | 可选 |

3. 填完保存，EdgeOne 会自动重新发布。

> **这些密钥去哪拿？** DeepSeek 在 platform.deepseek.com 注册后「API Keys」页面复制；CloudBase 在腾讯云控制台（console.cloud.tencent.com/tcb）新建环境后，在「API Key 配置」生成 Publishable Key。
> **这一步不急**——先发布看效果也完全没问题，密钥以后随时能补。
> **注意**：`DEEPSEEK_API_KEY` 和 `CLOUDBASE_*` 都是**服务端密钥**，只填在部署平台的环境变量里，不要写进代码或公开仓库。

> 💡 关于数据库：本项目**不**再用 Supabase（它在国内常打不开），公共画廊改为腾讯云 CloudBase（PostgreSQL 模式）。不填 CloudBase 两个变量，画廊会显示「还没开放」，但本地收藏和主流程照常。
